### 1. [ConfidenceOS — AI Interview Confidence Coach](https://github.com/kirthistaank/MIDS/tree/main/ConfidenceOS)

> A full-stack agentic AI app that helps job seekers practice interviews, reframe self-doubt, and negotiate offers — running entirely on your local machine.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![LangGraph](https://img.shields.io/badge/Agent-LangGraph-purple)
![Pinecone](https://img.shields.io/badge/VectorDB-Pinecone-green)

![FastAPI](https://img.shields.io/badge/API-FastAPI-red)
![License](https://img.shields.io/badge/license-MIT-lightgrey)

**What it demonstrates:**
- End-to-end **LangGraph agentic loop** with tool calling, memory, and emotion detection
- **Hybrid RAG** — dense (Pinecone) + sparse (BM25) search with cross-encoder reranking
- **Knowledge graph** retrieval via Neo4j AuraDB (Cypher query generation)
- **Multi-mode coaching** — Mock Interview, CBT Reframe, Salary Negotiation, STAR Coach
- **Voice input** via Web Speech API with live confidence scoring
- **Modular architecture** — prompts, tools, memory, emotion all fully decoupled
- Rotating log system, full retrieval tracing, zero API cost

### 2. [CareTrace — Neurosymbolic Pediatric Triage System](https://github.com/kirthistaank/MIDS/tree/main/NueroSymbolic_Agentic_AI/CareTrace)

> An intelligent pediatric after-hours triage system for febrile illness, GI symptoms, and dehydration risk with explicit medication safety hooks and antibiotic stewardship flags.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![LangGraph](https://img.shields.io/badge/Agent-LangGraph-purple)
![Neo4j](https://img.shields.io/badge/GraphDB-Neo4j_SNOMED-teal)
![PyDatalog](https://img.shields.io/badge/Rules-PyDatalog-orange)
![Streamlit](https://img.shields.io/badge/UI-Streamlit-red)

**What it demonstrates:**
- **Neurosymbolic architecture** — LLM-based interpretation + symbolic safety rules (PyDatalog)
- **Knowledge graph retrieval** — SNOMED CT mini-KG via Neo4j for clinical concept mapping
- **LangGraph orchestration** — interpret → KG retrieval → safety logic → clinical explanation
- **Clinical safety** — Rule-based triage with audit trails, antibiotic stewardship, medication safety hooks
- **Evidence-based** — Seattle Children's Fever CPG integrated with traceable rule firing
- **Interactive UI** — CLI and Streamlit interfaces with scenario-based evaluation
