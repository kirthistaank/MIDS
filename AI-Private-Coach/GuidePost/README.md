# MIDS Data Science Capstone Project: Guidepost

We propose an AI-powered interpersonal dynamics coaching system that helps individuals better understand how they communicate and engage with others in real-world interactions. The system analyzes audio recordings of conversations provided by the user, identifies communication patterns and interaction dynamics, and delivers personalized feedback aligned with the user’s goals for growth.

The system processes each interaction across three dimensions:
- What was said (language patterns),
- How the conversation flowed (turn-taking, interruptions, balance of participation), and
- How things were said (vocal delivery features such as pace or intensity).

Using these signals, the system identifies relevant interaction patterns and maps them to the user’s stated goals. The system provides observational, evidence-based feedback, highlights recurring patterns over time, and suggests practical strategies for future interactions.
